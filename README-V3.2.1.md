仅针对 V3.2 网页顺序验收。保留 server.py、start.sh、discover_sut.py 和本地 API/身份校验修复。

安装前停止网页，确认官方 Canvas 没有排队/运行任务且长测已结束；解压后运行 python3 install_v321.py --target /实际/cpu_ai_validation --apply。默认不加 --apply 是只读预检查。若文件哈希与 V3.2 基线不符则拒绝覆盖。安装器输出 BACKUP 路径，回滚使用 --rollback 实际路径。

升级后旧待审批流程须放弃，重新录入/确认供应商规格与授权，重新探测、审批。最大延迟留空即仅测量模式；有值即正式模式。两个负载授权仍必须真实取得。

只有 CPU-07/08 所有计划组有效、证据及回执绑定校验通过、且唯一问题是缺阈值，才允许继续；CPU-09 必须验证本次全部阶段，最终 INCONCLUSIVE，不是 PASS。其余非 PASS 仍停止。CPU-10/12 仍自动分析，完整仅测量不触发故障分析 CPU-11。原始证据不改写。

直接命令行运行旧 workflow 仍按原规则停止；本补丁不修改其行为。真实 Automation API、远端压力、长测仍需现场验证。
